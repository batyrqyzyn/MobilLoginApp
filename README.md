# Campus Hub - Mobile Application (Lab 6)

## 📌 Project Overview
This project is part of the Mobile Application Development coursework at ALT University. In Lab 6, we performed a complete refactoring of the Campus Hub project to follow a clean and scalable directory architecture using React Native and TypeScript.

## 📁 Project Structure (`src/`)
- `components/` - Reusable UI components (`ServiceCard`, etc.)
- `data/` - Static data and mock arrays (`services.ts`)
- `screens/` - Application screens (`LoginScreen`, `HomeScreen`, `ServicesScreen`, `ProfileScreen`, `DetailsScreen`)
- `types/` - TypeScript type definitions (`service.ts`)
- `navigation/` - Stack and Bottom Tabs navigation configuration

## 🛠️ Tech Stack
- React Native / Expo
- TypeScript
- React Navigation (Stack & Bottom Tabs)
- Git & GitHub Version Control
